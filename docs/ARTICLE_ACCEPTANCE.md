# 图文来源验收

验收日期：2026-11-02。项目已统一命名为 DuckDownloader；包名、CLI 和仓库自带 skill 使用 `duckdownloader`。本地真实样例记录来自改名前的同一份实现，下载能力和限制保持有效。

## 飞书 docx

使用用户提供的获授权文档，在 macOS ARM64、Camoufox 156.0.1-beta.36 上完成手动登录、会话保存、无界面采集和正式 CLI 下载。最终 PDF 为 42 页 A4，48 个目录章节、48 张本地图片全部保留；清单无警告，图片字节数和 SHA-256 校验通过。章节与前次采集结果一致。

PDF 的全部正文、48 个标题及末尾内容通过独立文字检查，另检查整份缩略图与重点页面。macOS Quartz 对部分汉字输出了外观相同的 CJK 部首码位，例如“页”被提取为“⻚”；文字对照需先做 NFKC 和已知部首归一化，不能声称所有字符都能原样复制或精确检索。HTML 与 Markdown 保留原 Unicode 正文。

真实文档、登录数据、PDF、资源、截图和检查报告仅保存在本地忽略目录，不提交 Git。Lark 租户、复杂块、wiki、表格、多维表格、嵌入媒体以及 Windows/Linux 上这两种新来源的真实下载尚未验收。Scribd 原有的平台证据见其他验收文档。

## 微信公众号

用户提供的文章正文可读；图片发现、HTML/Markdown 转换、图片本地化、失败保护与原生打印通过离线或本地浏览器测试。真实文章有 4 个图片引用，但当前网络连接 `mmbiz.qpic.cn` 在 TLS 阶段断开，Camoufox、Playwright 请求上下文与 curl 均复现。未忽略图片，也未将文本归档当作完整下载。

正文与 partial 清单已保留到本地忽略目录；`canDownload` 仍为 false。需要网络可访问这些图片后重新运行真实样例，再启用公众号下载。此状态不是登录或验证码绕过问题。

## 测试边界

离线测试覆盖来源路由、参数传递、明确拒绝、滚动脚本、图片域名/重定向约束、隐藏脚本清除、部分结果保留、错误日志不携带请求头，以及失败时保留既有 PDF。本地 Camoufox 测试覆盖多页图文打印、字体和 A4 页框；这些测试不能代替其他文档的真实授权验收。

改名后的最终离线运行：224 项通过，9 项浏览器/联网测试默认跳过；7 项本地 Camoufox 测试另行通过，覆盖原生打印及会话持久化。typecheck、Biome check、build 与 git diff --check 通过。所有本次测试浏览器已关闭。
