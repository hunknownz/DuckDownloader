# 本地 HTML / Webarchive 转换验收

验收日期：2026-11-03。本地平台为 macOS ARM64，使用项目锁定的官方 Camoufox TypeScript SDK、编译后的 `node dist/cli.js convert` 和共享 A4 原生 PDF 后端；没有直接打印原网页、截图拼接或联网补取图片。

## 原生运行与独立检查

| 输入 | PDF 页数 | 已核对图片 | 结果 |
| --- | ---: | ---: | --- |
| HTML，包含中文、英文、列表、引用、表格、代码和图注 | 4 | 1 | 完整，清单无警告 |
| XML plist Webarchive，同一正文与归档图片 | 4 | 1 | 完整，清单无警告 |
| 二进制 plist Webarchive，同一正文与归档图片 | 4 | 1 | 完整，清单无警告 |
| 前次获授权、已保存的完整真实 HTML 与本地图片 | 44 | 48 | 完整，清单无警告 |

三种格式分别核对原始输入的 37 个文字片段，真实保存网页核对 271 个文字片段，均按原顺序进入 PDF。独立使用 pypdf 检查全部 A4 页框，使用 Pillow 核对图片可解码性，并校验每个本地资源的字节数与 SHA-256。原有真实源文件的哈希保持不变。

三种格式的全部四页经 Poppler 渲染后逐像素一致，并逐页查看一套完整渲染图。真实保存网页检查全部 44 页的缩略图，以及第 1、22、44 页的放大图，核对首尾正文、章节、图片和页边界，未发现裁切或重叠。中间资料和实际内容仅位于本地忽略目录，不提交 Git。

macOS Quartz 的文字提取仍需 NFKC、已知 CJK 部首及双倍破折号的兼容归一化；不能据此声称源码中的每个字符都可逐字复制。转换不会自动 OCR，也不恢复保存网页中缺失的内容。

## 清理与失败保护

- 默认保留 HTML 与二进制 Webarchive 源文件；`--keep-intermediates` 保留内容结构、排版文件、图片和清单。
- 正式 CLI 使用 `--cleanup-source` 成功删除指定 XML Webarchive；另一个 HTML 样例成功后删除源文件并自动清理中间目录，原有资源目录保持可用。
- 缺图样例返回退出码 1，保留 partial 正文与警告，源文件和既有 PDF 均保持不变。
- 回归测试覆盖导出/浏览器关闭失败、转换时源文件改变、目录逃逸、图片符号链接、无效归档、自定义 XML 实体、大小限制和未适配子框架。

无独立标题的公众号文字消息按首行与空行重排，排除正文容器中的页面元信息；超长首行不会使正文丢失。没有标题元数据的普通 HTML 会使用已有 h1，显式 `--title` 会保留原来的正文首行。

## 测试与平台范围

本次提交版本有 299 项离线测试通过，12 项浏览器/联网测试默认跳过；另行运行的 10 项本地 Camoufox 测试全部通过，其中 HTML、XML Webarchive 和二进制 Webarchive 的测试均使用真实原生 PDF 导出，且页面没有发起 HTTP/HTTPS 请求。

全局覆盖率：语句 89.61%、分支 82.03%、函数 85.90%、行 91.41%，均达到 80% 阈值。typecheck、Biome check、build 和 git diff --check 通过。

Windows/Linux 离线检查由常规 CI 执行；Windows 原生转换可通过现有 Windows smoke 工作流运行三种格式测试，结果以对应 GitHub run 为准。以上本地真实文件与视觉验收记录限于 macOS，不代表所有保存网页、嵌入媒体或 Linux 原生浏览器均已验收。
